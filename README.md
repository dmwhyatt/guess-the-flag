# guess-the-flag
stupid game inspired by cucbc flag woes

A static quiz: read a (fictitious) rowing scenario, guess which CUCBC flag the Cam would be under.

## Editing
All game text lives in `content.js`: write each scenario's `text`, and rewrite the end-of-game `VERDICTS`.
Scenarios with empty `text` show their underlying conditions with a DRAFT tag.

## Running
Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main`, `/ (root)`).

Flag rules: https://cucbc.org/handbook/flag. Flag images © CUCBC. Not affiliated with CUCBC.
